# 🏆 Pitch Platform - Hackathon Submission

> **AI-Powered Sales Pitch Evaluation with Real-time Feedback & Gmail Integration**

## 🚀 Quick Start (30 seconds)

```bash
pnpm install && pnpm dev
open http://localhost:3000
```

## 🎯 What It Does

**Real-time pitch evaluation** that helps sales teams improve their pitches by:
- Evaluating against 8 proven criteria
- Providing instant feedback and suggestions  
- Automating follow-up emails via Gmail
- Tracking success rates and performance

## 🏗️ Fullstack Agent Architecture

- **Frontend**: Next.js + CopilotKit for agentic UI
- **Backend**: FastAPI + LlamaIndex for AI evaluation
- **Integrations**: Composio for Gmail API
- **Real-time**: Live feedback and progress tracking

## 🎮 Demo Flow (5 minutes)

1. **Select Company** → Choose from 4 realistic companies
2. **Start Pitch** → 2-minute timed evaluation
3. **Type Pitch** → Get real-time feedback on 8 criteria
4. **View Results** → See score and what was missing
5. **Send Email** → Create Gmail draft for follow-up
